Rendimiento Maximo de Throughput

Analisis matematico del rendimiento de un servidor web

¿Que es el Throughput?

El throughput representa la cantidad de transacciones que un servidor puede procesar por segundo. El objetivo es encontrar la cantidad optima de hilos concurrentes para obtener el mayor rendimiento.

Procesador de referencia

Intel Core i9-13900T

Nucleos: 24

Hilos: 32

CPU Mark: 42839

TDP tipico: 35 W

Los datos del procesador se consultaron en PassMark. Este modelo tambien se encuentra disponible en equipos como el Lenovo ThinkCentre M90q Gen 4.

Consultar ficha del procesador en PassMark

Modelo matematico

Se utiliza una funcion hipotetica para representar el comportamiento del throughput:

T(x) = 1000x / (1 + (x/32)²)

Donde x representa los hilos concurrentes y T(x) representa las transacciones por segundo.

El modelo toma como referencia los 32 hilos del procesador. El parametro 1000 es una constante hipotetica de escala.

Resultados de la simulacion

Hilos optimos

32

Rendimiento maximo

16.000 TPS

Primera derivada

0

Segunda derivada

-15.625

Grafica del rendimiento

El rendimiento aumenta hasta alcanzar su maximo en 32 hilos concurrentes. Despues de ese punto, el modelo representa una disminucion del throughput.

Conclusion

Mediante el calculo diferencial se encontro que el modelo alcanza su rendimiento maximo con 32 hilos concurrentes, obteniendo 16.000 TPS estimados.

La primera derivada es igual a cero y la segunda derivada es negativa, lo que confirma que el punto corresponde a un maximo local.

Es importante aclarar que los resultados corresponden a una simulacion matematica y no a una prueba real de rendimiento del procesador.
