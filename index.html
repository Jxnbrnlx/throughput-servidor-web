Rendimiento Maximo de Throughput

Analisis matematico del rendimiento de un servidor web

¿Que es el Throughput?

El throughput representa la cantidad de transacciones que un servidor puede procesar por segundo. Nuestro objetivo es encontrar la cantidad optima de hilos concurrentes para obtener el mayor rendimiento.

Modelo matematico

Utilizamos la siguiente funcion para representar el comportamiento del servidor:

T(x) = 500x / (1 + 0.0025x²)

Donde x representa los hilos concurrentes y T(x) representa las transacciones por segundo.

Resultados de la simulacion

Grafica del rendimiento

Se observa como el rendimiento aumenta hasta alcanzar su maximo en 20 hilos y posteriormente disminuye.

Conclusion

Mediante el uso de calculo diferencial encontramos que el rendimiento maximo del modelo se alcanza con 20 hilos concurrentes, procesando 5000 transacciones por segundo.

La segunda derivada negativa confirma que el punto encontrado corresponde a un maximo.
